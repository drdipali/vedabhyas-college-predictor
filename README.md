# 🌿 Vedabhyas College Predictor (वेदअभ्यास)
### Powered by Ayush Gurukulam

> An AIAPGET (Ayurveda PG - MD / MS) admission predictor and student counseling management portal for BAMS graduates across India.

🌐 **Live Website**: [https://drdipali.github.io/vedabhyas-college-predictor/](https://drdipali.github.io/vedabhyas-college-predictor/)

---

## 🏛️ Features

- **25+ Real Colleges Database**:
  - Apex National Institutes (AIIA New Delhi, NIA Jaipur, ITRA Jamnagar, IMS BHU Varanasi, NEIAH Shillong)
  - State Government Colleges across 12+ States (Maharashtra, Karnataka, Kerala, UP, Gujarat, Delhi, etc.)
  - Top Deemed & Private Universities (SDM Udupi/Hassan, KLE Belagavi, BVDU Pune, DY Patil, Patanjali, Amrita)
- **Authentic Metrics**: Closing cutoffs (All India AYUSH & State Quotas across General, OBC, SC, ST, EWS), monthly PG stipends (₹45k–₹1.15L/month), annual tuition fees, hospital bed capacity, and clinical branches.
- **Strict Verification Gate**: Predictor is locked until candidate verifies their **Mobile Number** and **Email ID**, providing BAMS graduation details and preparation mode.
- **Hidden & Protected Admin Portal**:
  - Discreetly accessed via the top navbar or footer `🔒 Faculty Admin Portal`
  - Secured with custom faculty passcode
  - Real-time candidate lead directory with full student dossiers
  - Instant manual candidate addition (`➕ Add Candidate Lead`)
  - One-click CSV Export for student outreach and counseling follow-ups
- **Spatial UI/UX**: Antigravity glassmorphic design, smooth GSAP micro-interactions, responsive mobile layout.

---

## 🚀 Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS, Lucide React Icons
- **Animations**: GSAP (GreenSock Animation Platform)
- **Hosting**: GitHub Pages via GitHub Actions CI/CD (`.github/workflows/deploy.yml`)

## 🛠️ Local Development

```bash
# Install dependencies

# Start local dev server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```
